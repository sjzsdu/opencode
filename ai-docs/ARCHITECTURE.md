# OpenCode 架构设计

## 系统概览

OpenCode 采用客户端/服务器架构设计，核心是一个 AI 驱动的代码助手，通过工具系统与文件系统、终端等交互。

## 核心组件

### 1. 会话引擎 (Session Engine)

负责管理 AI 对话的生命周期。

```
┌─────────────────────────────────────────────────────────────┐
│                    Session Engine                           │
│                                                             │
│  ┌──────────┐    ┌──────────────┐    ┌──────────────────┐  │
│  │  User    │───▶│   Message    │───▶│  LLM Processor   │  │
│  │  Input   │    │   Queue      │    │                  │  │
│  └──────────┘    └──────────────┘    └────────┬─────────┘  │
│                                                │            │
│        ┌───────────────────────────────────────┘            │
│        ▼                                                        │
│  ┌──────────────┐    ┌──────────────┐    ┌────────────────┐  │
│  │    Tool      │◀───│   Tool       │───▶│    File       │  │
│  │   Executor   │    │  Registry    │    │   System      │  │
│  └──────────────┘    └──────────────┘    └────────────────┘  │
│                                                             │
│  ┌──────────────────────────────────────────────────────┐   │
│  │                   SQLite Database                     │   │
│  │  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────────────┐ │   │
│  │  │Session │ │Message │ │  Part  │ │     Todo      │ │   │
│  │  │ Table  │ │ Table  │ │ Table  │ │    Table      │ │   │
│  │  └────────┘ └────────┘ └────────┘ └────────────────┘ │   │
│  └──────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

**处理流程：**

1. 用户输入进入消息队列
2. 消息经过处理后发送到 LLM
3. LLM 返回可能包含工具调用
4. 工具注册表查找对应工具
5. 工具执行器执行工具
6. 执行结果返回给 LLM
7. 最终响应返回给用户

## 数据流

### 主请求流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant CLI as CLI/Web
    participant Server as HTTP Server
    participant Session as Session Engine
    participant LLM as AI Provider
    participant Tool as Tool System
    participant DB as SQLite
    participant LSP as LSP Server

    User->>CLI: 输入请求
    CLI->>Server: POST /session/:id/message
    Server->>Session: 处理消息
    Session->>DB: 存储消息
    Session->>LLM: 发送对话
    LLM-->>Session: 返回响应
    alt 包含工具调用
        Session->>Tool: 执行工具
        Tool->>LSP: 请求语言服务
        LSP-->>Tool: 返回结果
        Tool->>DB: 记录执行结果
        Tool-->>Session: 返回工具结果
        Session->>LLM: 发送工具结果
    end
    Session-->>CLI: 流式返回响应
    CLI-->>User: 显示结果
```

### 文件编辑流程

```mermaid
sequenceDiagram
    participant AI as AI Model
    participant Edit as Edit Tool
    participant Diff as Diff Engine
    participant FS as File System

    AI->>Edit: 生成编辑指令
    Edit->>Diff: 解析编辑
    Diff->>FS: 读取原文件
    FS-->>Diff: 返回内容
    Diff-->>Edit: 生成差异
    Edit->>FS: 应用变更
    FS-->>Edit: 确认完成
    Edit-->>AI: 返回结果
```

## 存储架构

### SQLite 数据库表

```mermaid
erDiagram
    Project ||--o{ Session : contains
    Session ||--o{ Message : contains
    Message ||--o{ Part : contains
    Session ||--o{ Todo : has

    Project {
        string id PK
        string directory
        string title
        timestamp created_at
        timestamp updated_at
    }

    Session {
        string id PK
        string project_id FK
        string parent_id
        string slug
        string directory
        string title
        string version
        json permission
    }

    Message {
        string id PK
        string session_id FK
        json data
        timestamp created_at
    }

    Part {
        string id PK
        string message_id FK
        string session_id
        json data
        timestamp created_at
    }

    Todo {
        string session_id FK
        string content
        string status
        string priority
        int position
    }
```
